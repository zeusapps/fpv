# Pavo20 Pro II 4S (Cube G473_V3) - SBUS / DJI Remote Controller 3
#
# Base:  BetaFPV BF2025.12.5 Cube G473_30A Pavo20 Pro II ELRS 20260812
# Adds:  GPS on UART2 (BZGNSS BZ-181, NMEA 115200), this airframe's AUX layout,
#        OSD layout with GPS + O4 VTX temperature, Cine/Base/Scale-70 rate profiles
#
# REQUIRES the rewire described in GPS_SETUP.md:
#   LED yellow (data)       R2 (PA3)  -> T1 (PA9)
#   GPS yellow (module TX)  R1 (PA10) -> R2 (PA3)
#   GPS white  (module RX)  T1 (PA9)  -> T2 (PA2)
# R1/PA10 is shared with the DJI O4 air unit's SBUS output. GPS on UART1 with the O4
# connected puts two drivers on one net and corrupts the GPS data.
#
# AFTER PASTING: re-run Calibrate Accelerometer. Do not fly without it.
#
# NOTE: profile_name and rateprofile_name are limited to 8 characters. Longer names
# fail with "STRING MUST BE 1-8 CHARACTERS" and abort the whole batch at save.
#
# SBUS MODE - DJI Remote Controller 3.
# The RC3 has far fewer switches than the V12 MAX. PREARM on AUX3 will block arming
# if nothing is mapped to it. Either map a switch, or delete the "aux 5" line below.
# Telemetry over SBUS is limited: ELRS Lua GPS tracking is NOT available in this mode.
# OSD home distance and direction still work.

batch start
