# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This repository contains **Betaflight CLI configuration dumps** for a **BetaFPV Pavo20 Pro II**
2.2" ducted cinewhoop. These are not source code files — they are flight controller
configuration backups and tuned variants.

- **Airframe:** Pavo20 Pro II, ducted 2.2" cinewhoop, Gemfan D2.2 3-blade screw-mount props
- **Video:** DJI O4 Air Unit Pro on **UART4**, MSP DisplayPort (no analog VTX, no Betaflight OSD chip)
- **Radio:** HelloRadio V12 MAX with ExpressLRS, CRSF protocol
- **Board target:** `BETAFPVG473_V3` (4S / Cube G4 30A variant), manufacturer `BEFH`, STM32G474
- **GPS:** BZGNSS BZ-181 (u-blox M10) on UART1 — see `GPS_SETUP.md`
- **Firmware:** Betaflight 2025.12.2, MSP API 1.47
- **Tune goal:** cinematic/smooth — clean video over raw stick response

## File Structure

- `HARDWARE.md` — hardware reference, pin map, and the known firmware issue
- `SETUP_GUIDE.md` — first-flight setup order, from unbox to first hover
- `BINDING_GUIDE.md` — binding the HelloRadio V12 MAX to the onboard ELRS receiver
- `DJI_O4_SETUP.md` — DJI O4 Air Unit Pro wiring, MSP DisplayPort and OSD notes
- `GPS_SETUP.md` — BZ-181 GPS wiring, config and diagnosis
- `PAVO20PRO2_ELRS_V1.txt` — flight config, ELRS / HelloRadio V12 MAX
- `PAVO20PRO2_SBUS_V1.txt` — flight config, SBUS / DJI Remote Controller 3
- `dumps/` — CLI dumps. Keep the untouched factory dump here, named with the date it was taken.

Both V1 configs are built on BetaFPV's BF2025.12.5 stock dump and **require the GPS/LED rewire**
described in `GPS_SETUP.md`. They differ only in the `serial` block and `serialrx_provider`.

Naming convention (matching the Meteor75 repo): tuned variants go in the repo root as
`PAVO20PRO2_<purpose>_V<n>.txt`; raw factory dumps go in `dumps/` with ` - original` in the name.

## Betaflight CLI Config Format

These files use `diff all` format — they only contain settings that differ from Betaflight
defaults. They are applied by pasting into the Betaflight Configurator CLI tab.

Key sections in order: `defaults nosave` → board/MCU info → features → serial ports → beacons →
aux modes → master settings → PID profiles → rate profiles → `save`.

## Working with These Files

- When modifying configs, preserve the `batch start` / `defaults nosave` header and the `save` footer
- **Never copy `mcu_id`, `signature` or `acc_calibration` between quads** — they are per-board.
  `acc_calibration` in particular must be regenerated by re-levelling on the actual airframe.
- A config from the 3S variant will not run correctly on the 4S variant and vice versa.

### AUX mode IDs (Betaflight permanent box IDs)

| ID | Mode |
|---|---|
| 0 | ARM |
| 1 | ANGLE |
| 2 | HORIZON |
| 13 | BEEPER |
| 15 | LEDLOW (LED strip off) |
| 35 | TURTLE (flip over after crash) |
| 36 | PREARM |

Format: `aux <index> <mode_id> <channel> <range_low> <range_high> 0 0`

Channel numbers in aux lines are 0-indexed: `0`=AUX1/CH5, `1`=AUX2/CH6, `2`=AUX3/CH7, `3`=AUX4/CH8.

### Serial port function bitmask

`serial <index> <function_bitmask> <msp_baud> <gps_baud> <telem_baud> <blackbox_baud>`

Serial index is 0-based: `serial 0`=UART1, `serial 3`=UART4.

| Bit value | Function |
|---|---|
| 0 | disabled |
| 1 | MSP |
| 2 | GPS |
| 64 | SERIAL_RX |
| 128 | BLACKBOX |
| 1024 | ESC_SENSOR |
| 2048 | VTX_SMARTAUDIO |
| 8192 | VTX_TRAMP |
| 131072 | VTX_MSP |

`131073` = `131072 + 1` = VTX_MSP + MSP — this is the DJI air unit port.

### OSD

OSD position values are encoded integers:

```
value = x_low5 | (y << 5) | (x_bit5 << 10) | (profile_flags << 11)
profile 1 = +2048, profile 2 = +4096, profile 3 = +8192
```

A value **below 2048 is hidden** — the profile flag is what makes an element visible.
Prefer the Betaflight Configurator OSD tab to place elements rather than editing raw values by hand. Note that with the O4 the OSD canvas is
rendered by the air unit over MSP DisplayPort, so the canvas size differs from analog —
positions copied from an analog quad will land in the wrong place.
